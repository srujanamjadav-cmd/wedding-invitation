# Hema & Nitish — Modern Wedding Invitation

Open `index.html` with VS Code + Live Server.

## What is new
- 3D CSS perspective double-door opening
- Mobile swipe-up gesture to open
- Cinematic half-white / ivory / maroon / antique-gold theme
- Canvas-based floating gold particles
- Scroll-triggered reveal animations using IntersectionObserver
- Interactive 3D tilt photo card using pointer/touch movement
- Closing sequence where the bride/groom visual halves move together and the doors close
- Live countdown to 28 October 2026 at 7:30 PM IST
- Web Share API with clipboard fallback
- Add-to-calendar `.ics` download for both events
- Google Maps venue button
- Optional background music
- Responsive mobile-first design
- Reduced-motion accessibility support

## Optional music
Place a file named:
`assets/wedding-music.mp3`

The music button is already included. Browsers generally require the user to tap before audio can start.

## Run
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install/use Live Server.
4. Right-click `index.html` → Open with Live Server.

For a phone, open the Live Server network URL while the phone and computer are on the same Wi-Fi.
